The turns are hand-written and small, so one turn is about 2 points. Differences of one or two turns are noise. Tokens leave out the routers' own use.

## Memory, with all three servers running together

From `/usr/bin/time -l` on each server when it stopped, in the second of two runs (Apple M5, 16 GB, `--ctx-size 8192`). Model files are memory-mapped, so these numbers move with memory pressure: in the first run the 4B server showed 1,873 MB resident and 1,436 MB footprint, and alone it showed 3,337 MB and 1,266 MB. The three files total 8.7 GB, so treat that as the real need. All three ran together, and free memory reported by `memory_pressure` fell to 14% at its lowest reading.

| Server | Maximum resident MB | Peak footprint MB |
| --- | --- | --- |
| Qwen3.5 4B Q4_K_M (cheap) | 3081 | 695 |
| Qwen3.5 9B Q4_K_M (strong) | 2792 | 676 |
| EmbeddingGemma 2 Q8_0 (router) | 458 | 174 |

Cost is compute time and tokens, because everything runs locally and no money changes hands.

"Wrong values" counts outputs stating a detail, intent, selection or memory the label does not have. These are the silent failures, because a missing detail only makes the engine ask again.
